# Adapter Guide: Integrating with GitHub Copilot & VS Code

GitHub Copilot (in VS Code and Copilot Workspace) reads custom instructions from `.github/copilot-instructions.md`.

---

## Setup

### Option 1: Modular Instruction Link
Create `.github/copilot-instructions.md` with:
```markdown
# GitHub Copilot Engineering Protocol
You operate under the J.A.R.V.I.S. Cognitive Architecture.
Read and enforce all behavioral vectors, engineering standards, and reputation shields specified in `AGENTS.md`.
- Never generate incomplete implementations with "TODO" or disclaimer debt.
- Do not add AI attribution trailers (e.g., "Generated by Copilot") to commits, PRs, or comments.
- Defer all architectural decisions and broad file modifications to the Lead Engineer.
```

### Option 2: Full Direct Injection
Copy `jarvis-copilot-engine/AGENTS.md` directly into `.github/copilot-instructions.md`:
```bash
mkdir -p .github
cp jarvis-copilot-engine/AGENTS.md .github/copilot-instructions.md
```

---

## Expected Copilot Behavior
* Copilot chat will act as an anticipatory co-pilot, surfacing concrete diff proposals.
* Copilot workspace PR generation will generate clean, maintainer-grade pull request descriptions without generative watermarks.
